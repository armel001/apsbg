# Photos des membres

Déposez ici les photos de profil des membres (format carré de préférence,
`.jpg` ou `.png`, idéalement < 300 Ko chacune).

Le nom du fichier doit correspondre exactement à la colonne `photo` du
fichier `_data/membres.csv`, par exemple :

```
membres.csv  ->  photo = dossou-fabrice.jpg
assets/images/membres/dossou-fabrice.jpg
```

Si la colonne `photo` est laissée vide pour un membre, un avatar avec ses
initiales sera affiché automatiquement à la place — aucune photo n'est
obligatoire.
